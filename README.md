# Session sounds

[简体中文](README.zh.md)

Plays macOS system sounds through the desktop app, including while you’re in another app.

- **Glass** plays when a top-level conversation finishes a reply successfully.
- **Ping** plays when a question, plan review, or approval request is still waiting for your response.

Requires DeepSeek Harness Desktop 0.2.2-rc.5 or newer on macOS.
In **Plugins** → **Add plugin**, select this directory.
Sounds start when **Session sounds** is enabled.
Disable the plugin to mute both sounds, or adjust the macOS output volume.

See [project documentation](docs/README.md) for verification commands.
