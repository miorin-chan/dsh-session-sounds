# 会话声音提醒

[English](README.md)

用 macOS 系统提示音提醒你查看桌面会话。
切换到其他应用后仍可听到。

- **Glass** 在主会话本轮回复成功完成时播放。
- **Ping** 在助手提问、提交计划供审阅，或请求审批且仍在等待响应时播放。

需要 macOS 上的 DeepSeek Harness 桌面版 0.2.2-rc.5 或更新版本。
在 **插件** → **添加插件** 中选择本目录。启用 **会话声音提醒** 后即可使用。
可停用插件来关闭两种声音，音量由 macOS 输出音量控制。

验证命令见[项目文档](docs/README.md)。
